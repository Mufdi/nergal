## Open question (not changed here)

`terminal_paste` wraps the body even when the app has not enabled DECSET 2004. In an aux shell running a program without bracketed paste (`cat`, `read`), the markers show up as literal `^[[200~`. Standard xterm behavior is to wrap only when 2004 is on (wezterm `send_paste`, `WZ/.../mod.rs:820-843`). This changes the `terminal-wezterm` "Bracketed paste" contract, so it needs a decision.
